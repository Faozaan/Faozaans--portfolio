FAOZAAN ADEYEMO — PORTFOLIO WEBSITE

FILES
- index.html: page structure and content
- style.css: responsive dark-neon design and animations
- script.js: mobile menu, theme toggle, scroll reveal, scroll progress, hover tilt and demo contact form
- assets/: portrait and project preview crops from the generated reference design

RUN IT
1. Extract this folder.
2. Open index.html in your browser, or use VS Code + Live Server.
3. Internet is needed for Google Fonts and Material Symbols; the page layout and core CSS still work offline.

PERSONALISE BEFORE PUBLISHING
- Replace hello@example.com in index.html and script.js with your real email.
- Update GitHub, LinkedIn and X profile links in index.html.
- Replace the concept project preview images with real screenshots as your projects are completed.
- Edit the About, skills and services text so it accurately reflects your experience.
- The contact form opens a mail app; it does not send messages directly from a server. Connect Formspree, EmailJS or your own backend for real form delivery.
- Add your own CV file if you want a working Download CV button.

The portrait and project cards are cropped from the generated design image to keep the same visual direction. They are illustrative mockups, not proof that the pictured projects are live websites.
